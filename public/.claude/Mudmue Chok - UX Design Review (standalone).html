Design review · รออนุมัติก่อนลงมือ

MUDMUE Pick → MUDMUE Chok
ปรับตามคำแนะนำ UX 7 ข้อ

คงพาสเทล Mudmue เดิมไว้ทั้งหมด (น้ำเงิน #0000ff = action หลัก, ชมพู #ff1493 = destructive, เทา = neutral) และทีมยังเป็น แดง/น้ำเงินเหมือนเดิม เพราะเป็น "สีข้อมูล" ไม่ใช่ accent — งานนี้คือจัดบทบาทสีให้ชัด ไม่ใช่เปลี่ยนธีม

✓ rename ป้าย + route /pick → /chok (ทำแล้ว) 7 ข้อด้านล่าง = รออนุมัติ แผงตัวอย่างล็อกโหมดสว่างตามหน้าเว็บจริง
1

แยกบทบาทสีให้มีความหมาย

accent ใช้เฉพาะ action หลัก/ไฮไลต์ผลลัพธ์ ไม่ใช่ระบายทุกที่แบบสุ่ม

ปัญหาที่แก้

  • ปุ่มเด่นที่สุดในหน้าตอนนี้เป็น ชมพู outline ส่วนปุ่มรองเป็น น้ำเงิน — สลับบทบาทกัน
  • text-[#CACAFB] บนพื้นขาว contrast ≈ 1.4:1 (ต่ำกว่าเกณฑ์ 4.5:1)
  • ชมพูใช้ทั้งเลขลำดับแถว และปุ่ม Delete — ตาแยกไม่ออกว่าอันไหนกดได้

ไฟล์ที่แตะ

  • MudmueMatchmaker.tsx — Random เป็น primary
  • MudmueProfile.tsx — หัวตาราง/ลำดับแถวเป็น neutral, Edit เป็น ink
  • MudmueButton.tsx — เพิ่ม tone neutral (ไม่แตะ theme เดิมที่หน้าอื่นใช้)
2

เพิ่มขนาดจุดกด ≥ 44px

ปุ่ม +/-, eye, trash, replay ทุกอันต้อง ≥44px เพื่อกดง่ายบน tablet

เกณฑ์

  • WCAG 2.5.8 (AA) ขอ 24px, Apple/Material ขอ 44/48px — ใช้ 44px ตามที่พี่สั่ง
  • ปุ่ม +/− ใน ScoreStepper อยู่ติดกันแนวตั้ง → เพิ่ม gap 4px กันกดพลาด

ไฟล์ที่แตะ

  • ScoreStepper.tsx (+/−)
  • MudmueMatchmaker.tsx (eye, trash, add, reset)
  • MudmueHistory.tsx (replay), MudmueDashboard.tsx (complete)
3

ใช้ badge แทนถ้วยรางวัล

ผลแพ้ชนะใน History ควรเป็น badge สีตามระบบ (accent = ชนะ, neutral = แพ้)

ปัญหาที่แก้

  • อ่านผลได้ทุก breakpoint (ของเดิมหายใต้ 1200px)
  • เลิก animation ที่วนไม่จบใน list ยาว — คนละเรื่องกับความสนุกในหน้า Dashboard
  • เคสเสมอมีสถานะของตัวเอง

ไฟล์ที่แตะ

  • ScoreStepper.tsx — showTrophy → result?: "win"|"lose"|"draw"
  • MudmueHistory.tsx — ส่ง result จาก d.winner
  • Dashboard ไม่ส่ง result (แมตช์ยังไม่จบ) → ไม่มี badge เหมือนเดิม
4

Level มีคำอธิบาย

Level ใน Profile (S, BG) ควรมี tooltip/legend บอกความหมาย ไม่ใช่โชว์ code ดิบ

ขอบเขต (ตามที่พี่เลือก)

  • บอกแค่ ลำดับ ไม่ใส่คำบรรยายที่ผมไม่รู้จริง
  • ลำดับมาจาก LEVEL_LIST ที่มีอยู่ (BG, N, S, P, C, B, A ตามลำดับใน array)
  • legend โผล่ใน Profile + ใน modal เลือกผู้เล่นของ Matchmaker (ที่มีคอลัมน์ Level ด้วย)

ต้องเช็คกับพี่

  • ลำดับใน array ปัจจุบันคือ BG → N → S → P → C → B → A — ถ้าลำดับจริงไม่ใช่แบบนี้ บอกได้ ผมแก้ทั้ง legend และ tooltip ที่เดียว
5

Layout ตอบสนอง

จาก fixed desktop layout เป็น grid ที่ยุบ sidebar เป็นแถบ tab แนวนอนบนจอแคบกว่า 900px

ปัญหาที่แก้

  • ความกว้างตายตัว w-[200px] lg:w-[360px] + gap 64px ทำให้การ์ดล้นบนแท็บเล็ตแนวตั้ง
  • h-[182px] ใน History ตัดเนื้อหาทิ้งเมื่อชื่อยาว/เล่นคู่
  • h-[800px], h-[1000px] ใน Matchmaker เหลือช่องว่างเปล่ามหาศาลบนมือถือ

ไฟล์ที่แตะ

  • MudmuePickPage.tsx — nav ชุดเดียว + grid
  • components/TabMenu.tsx — ถูกแทนที่ (จะลบถ้าไม่มีที่อื่นใช้)
  • ทั้ง 4 หน้าย่อย — ถอดความกว้าง/ความสูงตายตัว
6

ลำดับชั้น typography

แยก heading/label/body ด้วยขนาด-น้ำหนักต่างกัน ไม่ใช่ตัวหนังสือขนาดใกล้เคียงกันหมด

วิธีทำ

  • เพิ่ม type tokens ในไฟล์สไตล์ของหน้า Chok (ไม่แตะ index.css ที่หน้าอื่นใช้ร่วม)
  • ยังเป็น Noto Sans ตัวเดิม — ต่างกันด้วยขนาด/น้ำหนัก/สี ไม่เพิ่มฟอนต์ใหม่

ไฟล์ที่แตะ

  • ไฟล์ใหม่ mudmue-pick/chok.styles.ts — tokens + primitives ของหน้านี้
  • ทั้ง 4 หน้าย่อย — เลิก text-[28px] กระจัดกระจาย
7

Interaction state ที่จับต้องได้

hover/focus/pressed ต้องเห็นชัด ไม่ใช่ browser default (native select/checkbox เดิม)

สถานะที่ให้ครบทุกตัว

  • hover — พื้นเปลี่ยน / ขอบเข้มขึ้น
  • focus-visible — ring น้ำเงิน 3px (เห็นชัดเวลากด Tab)
  • pressed — พื้นเข้มขึ้น + ขยับลง 1px
  • disabled — จาง + cursor:not-allowed + บอกเหตุผล

ไฟล์ที่แตะ

  • chok.styles.ts — Segmented, Check, Field, Select
  • MudmueMatchmaker.tsx, MudmueProfile.tsx — เปลี่ยนมาใช้

2 เรื่องที่อยากให้พี่เคาะก่อน

  1. สี badge "WIN" — คำแนะนำบอก "accent = ชนะ" ซึ่งในพาสเทลคือน้ำเงิน แต่ทีมน้ำเงินก็ใช้ #0000ff เหมือนกัน เลยอาจอ่านเหมือน "ฝั่งน้ำเงินชนะ" ทั้งที่จริงคือฝั่งแดงชนะ
    WIN ก. น้ำเงิน = accent ตามคำแนะนำตรงๆ WIN ข. ink ทึบ = เป็นกลาง ไม่ชนสีทีม
    ผมเอนไปทาง ข. เพราะ badge อยู่ติดกับคะแนนของทีมที่มีสีอยู่แล้ว — แต่พี่เคาะ
  2. ของสนุกในหน้า Dashboard — หมัดชนกัน (punch-left/right), aura เต้น, ตอนกดจบแมตช์ ผมจะ ไม่แตะ ทั้งหมด รวมถึงรูเล็ตและอนิเมชันผลการสุ่ม — เป็นบุคลิกของเว็บ ไม่ใช่ปัญหา UX ที่พี่ยกมา ถ้าอยากให้จัดด้วยบอกได้
